# Sudhir — AI & Software Developer Portfolio

A modern, high-performance portfolio website built with React, Vite, and Tailwind CSS. Featuring custom retro-modern pixel art animations, interactive terminal styling, showcase cards for selected projects, and multi-channel contact capabilities.

🔗 **Live Portfolio**: [https://sudhir128.github.io/sudhir-portfolio/](https://sudhir128.github.io/sudhir-portfolio/) (or custom domain / Vercel deployment)

---

## ⚡ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: Lightweight inline SVGs
- **Typography**: Syne, DM Sans, IBM Plex Mono

---

## 🚀 Key Features

- **Dynamic Pixel Art Canvas**: Custom 60x36 SVG animation with 8-bit character anatomy, streaming dual-monitor code stations, and celebratory handshake scenes.
- **Project Showcase**: Standardized alternating 2-column layout with browser chrome window headers and live links:
  - *King's Auction App*
  - *Privacy Risk Guard*
  - *ProBikers Inventory*
  - *QIQ Market Research Agent*
  - *AU Sports Management App*
- **Terminal Contact Form**: Interactive `~/new-message` terminal with asynchronous email dispatch, direct 1-click Gmail Web integration, default mail app fallback, and 1-click clipboard copy.
- **Retro-Modern Aesthetics**: Neon green `#B7FF5A` accents, dark theme background `#0B0B0D`, subtle grid textures, and smooth micro-interactions.

## 🛠️ Local Development

### 1. Clone the repository
```bash
git clone https://github.com/Sudhir128/sudhir-portfolio.git
cd sudhir-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```

The production-ready assets will be generated in the `dist/` directory.

---

## 🚢 Deployment

### Deploy to Vercel
1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset: `Vite`.
3. Click **Deploy**.

### Deploy to Netlify
1. Connect your GitHub repository on [Netlify](https://netlify.com).
2. Build command: `npm run build`.
3. Publish directory: `dist`.
